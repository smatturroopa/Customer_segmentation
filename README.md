# Customer Segmentation Analysis

## Project Overview

This project analyzes customer shopping behavior and segments customers into different groups using data analysis and K-Means clustering.

## Dataset

The dataset contains customer information such as:

- Age
- Purchase Amount
- Review Rating
- Previous Purchases
- Discount Applied
- Subscription Status
- Payment Method
- Season
- Location
- Product Category

## Tasks

### Task 1: Product Categories and Discounts
Identify product categories where discounts should be applied based on order volume, purchase amount, ratings, and existing discount usage.

### Task 2: Card Spending Analysis
Analyze Credit Card and Debit Card spending based on:

- Age groups
- Seasons
- Locations

### Task 3: Customer Segmentation
Use K-Means clustering to divide customers into 3 groups based on customer behavior and spending characteristics.

## Conclusion

The analysis helps identify customer groups and provides a basis for targeted marketing campaigns based on customer spending and behavior.
